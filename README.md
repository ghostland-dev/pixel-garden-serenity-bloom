# Pixel Garden Harmony

Relaxing pixel-art gardening game.

## Features

- Grow a garden to attract visitors

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/pixel-garden-serenity-bloom.git
cd pixel-garden-serenity-bloom
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
